react-blur

React component for creating blurred backgrounds using canvas.
Amount of blur 16px
How to use:
// pnpm add react-blur
import Blur from 'react-blur'
[...]
<Blur blurRadius={5} img={'path.jpg'} />
For more information see the github repo.
